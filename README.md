## 📖 介绍
雾屿 Misie 是一个本地单文件HTML导航页，**无后端，数据全部存在浏览器本地**
内置国内/海外双版本切换、多源壁纸、Favicon图标抓取、天气粒子特效、书签管理、导入导出备份。

## 🚀 使用方式
1. 下载 `index.html`
2. 直接浏览器打开，或者设置成浏览器新标签页
3. 打开右上角控制中心，切换国内/海外源

## ✨ 功能清单
- 🌐 国内 / 海外 双配置，自动适配搜索引擎与书签
- 🖼️ 多源壁纸API，国内外均可加载，兜底渐变防白屏
- 🔖 书签增删编辑，自动抓取网站Favicon
- 🌧️ 天气粒子：无 / 下雨 / 下雪 / 雨夹雪，切后台自动暂停
- ⌨️ 快捷键支持：ESC关闭弹窗、/ 聚焦搜索框
- 💾 书签配置导出 / 导入备份
- 🎨 深色/浅色模式
- 🤍 捐助入口：免费午餐、联合国儿童基金会
