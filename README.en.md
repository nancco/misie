# Misie

> ✨ Sci-fi style new tab page

[中文](./README.md) | [English](./README.en.md)

👉 [Live Demo](https://nancco.github.io/misie/)

## 📖 Intro
Misie is a single-file local HTML startpage. No backend, all data stored locally in your browser.
Built-in CN/Global profile switcher, multi-source wallpaper, favicon fetcher, weather particle effect, bookmark manager, import & export.

## 🚀 How to use
1. Download `index.html`
2. Open it directly in browser, set as your new tab
3. Open control panel to switch CN / Global source

## ✨ Features
- 🌐 CN / Global two sets of config, separate search engine & bookmarks
- 🖼️ Multi-source wallpaper API, fallback gradient to avoid blank screen
- 🔖 Add, edit bookmarks, auto fetch favicon
- 🌧️ Weather particle: None / Rain / Snow / Sleet, pause when tab hidden
- ⌨️ Hotkeys: ESC close modal, `/` focus search
- 💾 Import & export bookmark backup
- 🎨 Dark / Light theme
- 🤍 Donate links: Free Lunch for Children, UNICEF
